# gen_tasks

Bug-fixing tasks generated by mutation from the seed libraries in `../seeds/` (352 tasks from 16 seeds). The task directories
(`g-<seed>-<n>-<family>/`, about 95 MB, they contain third-party library code, see `../THIRD_PARTY.md`) are **not committed**.
What is committed:

- `SPLIT.json`: the frozen split, **per seed library**: train 257 tasks (12 libraries), dev 48 (colorama, schema), test 47
  (sqlparse, xmltodict), each with the content hash of the task. The hash makes a changed task fail loudly.
- `SUBSETS.json`: `pilot30`, the 30 train tasks used for the teacher pilot.
- `GEN_REPORT.json`: per seed, how many mutants were tried and why the rejected ones were rejected.

Regenerate (needs Docker and the sandbox image, takes about an hour):

```bash
miniagent-eval sandbox-build
miniagent-eval gen --seeds seeds --out gen_tasks --per-seed 24 --workers 4
miniagent-eval --tasks-root gen_tasks verify --sandbox --workers 4     # every task must fail as shipped and pass with its solution
```

Generation is seeded (`--rng`), but mutants that time out or flake depend on the machine, so a regeneration can differ in
detail from the tasks that `SPLIT.json` describes; the content hashes there tell you whether it did.
