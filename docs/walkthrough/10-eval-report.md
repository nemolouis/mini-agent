# 10 · `miniagent/eval/report.py`:统计、报告、对比

**作用**:把很多条"运行记录"变成可读的结论:通过率(带置信区间)、成本、失败分布,以及两个版本的同题配对对比。

## 先懂两个统计概念

**① 为什么先"按任务平均"**
同一道题重复跑 3 次,这 3 次不是 3 个独立样本——它们都是"这道题"。所以先算每道题自己的通过率(如 2/3 ≈ 0.67),再对**题目**求平均。文件开头的 docstring 讲的就是这个。

**② bootstrap 置信区间**
只有十几道题时,通过率 60% 到底有多可靠?bootstrap 的思路:
1. 把"每题通过率"这批数,**有放回地**随机重抽(抽出和原来一样多的题,同一题可能被抽到多次);
2. 对这批重抽样本算平均;
3. 重复 2000 次,得到 2000 个平均值;
4. 排序后取第 2.5% 和第 97.5% 位置的值,就是 95% 置信区间。

区间越宽,说明结论越不稳。

## 逐个函数

**`load_records`(15–17 行)**:读 `runs.jsonl`,每行一个 JSON → 字典列表。`if l.strip()` 跳过空行。

**`_mean`(20–22 行)**:平均值。空列表时返回 `float("nan")`(NaN,"不是数字"),避免除零。`xs = list(xs)` 因为入参可能是生成器,只能遍历一次,先转成列表。

**`bootstrap_ci`(25–30 行)**
- 少于 2 个值无法估计,返回 NaN。
- `random.Random(seed)`:固定种子的随机数生成器,**每次运行结果一致**(评测要可复现)。
- `rng.choices(values, k=len(values))`:有放回抽样。
- `means[int(0.025 * n)]` 与 `means[int(0.975 * n) - 1]`:下界和上界。

**`per_task_pass`(33–37 行)**
- `defaultdict(list)`:字典,访问不存在的键时自动创建空列表,省去先判断。
- 返回 `{任务id: 该题通过率}`。`1.0 if r["passed"] else 0.0` 是条件表达式。

**`cost_of`(40–48 行)** 计算一次运行的花费
- 价格表按"每百万 token 多少美元"给出,分 `input`(未缓存输入)、`cache_read`(缓存命中)、`output`。
- 缺少价格时返回 `None`(报告里显示 n/a,而不是编造一个数)。
- 公式:各类 token 数 × 对应单价,加总后 `/ 1e6`。`1e6` 是 1,000,000 的科学计数写法。
- `tier`:`off_peak`(低谷价)或 `peak`(高峰价)。

**`summarize`(51–72 行)**:汇总指标字典
- `pass_rate` = 对任务平均后的通过率;`pass_rate_ci95` 为置信区间。
- 其余是各项均值:步数、输入/输出 token、成本、耗时、工具报错次数。
- `runs_with_compaction`、`tampered_runs`:发生过压缩/动过测试的运行数。
- `failure_classes`:`Counter` 统计每个失败类别出现次数。
- 内部函数 `mean_cost(tier)`(54–56 行):只要有一条记录算不出成本,整体就返回 `None`,避免"只有部分数据"导致误导。

**`_fmt`(75–76 行)**:格式化数字。`x != x` 是判断 NaN 的惯用法(NaN 是唯一不等于自身的值)。`f"{x:.{nd}f}"` 里嵌套花括号:先代入 `nd`,再作为小数位数。

**`markdown_report`(79–117 行)**:生成 Markdown 报告
- `lines = [...]` 一行行拼内容,最后 `"\n".join(lines)`。
- `*([...] if 条件 else [])`:条件满足时展开插入一行,否则插入零行——"可选的一行"的惯用写法。
- `*[f"| {k} | {v} |" for ...]`:把列表推导的结果展开进外层列表。
- 失败类别按出现次数倒序:`sorted(items, key=lambda kv: -kv[1])`,`key` 指定排序依据,取负数即倒序。
- 若成本为 `None`,末尾加提示"去 `configs/prices.json` 填价格"。

**`compare`(120–134 行)**:同题配对对比 A、B 两次实验
- 只比较**两边都有的题**(`set(pa) & set(pb)` 交集)。
- `diffs`:每题 `B - A` 的通过率差;对它做 bootstrap 得到差值的置信区间(**配对**比较比分别比较更有统计力)。
- `improved` / `regressed`:B 比 A 好/差的题列表;`unchanged` 为数量。
- 另外记录只出现在 A 或只出现在 B 的题。

**`markdown_compare`(137–151 行)**:把对比结果排版成 Markdown;`{...:+.1f}` 的 `+` 表示显示正负号;末尾提示"题少时区间很宽,小差异视为噪声"。
